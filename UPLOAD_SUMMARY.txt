NEXT STEPS FOR PyPI UPLOAD:
================================================================================

To upload the wheel to PyPI, you need:

1. PyPI account (create at https://pypi.org/register/)
2. API token (generate at https://pypi.org/manage/account/tokens/)
3. Run upload command:

   Option A (Interactive - Recommended for first time):
   $ twine upload dist/pynetworkintel-0.2.0-py3-none-any.whl
   (Will prompt for username/password)

   Option B (Using token):
   $ export TWINE_USERNAME="__token__"
   $ export TWINE_PASSWORD="pypi-AgEI..."  # Your API token
   $ twine upload dist/pynetworkintel-0.2.0-py3-none-any.whl

4. Verify upload:
   $ pip install pynetworkintel==0.2.0
   $ pynetworkintel --version
   # Should show: cli.py 0.2.0

See RELEASE_INSTRUCTIONS.md for detailed steps.
